# Changelog

All notable changes to **this project's** `.claude/CLAUDE.md` (開發規範) will be documented in this file.

> **This file ships as an empty seed.** When you adopt the claude-code-setup-v1 template, the `maintaining-claude-md` skill's Workflow A automatically writes your project's initial `v1.0.0` entry below during first customization. All subsequent rule changes append here in one commit together with CLAUDE.md.
>
> For the **template itself's** version history (how claude-code-setup-v1 evolved across releases), see `CHANGELOG.md` at the template root — it does not ship with `.claude/`.

The format is based on [Keep a Changelog v1.1.0](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

變更分類說明：
- **Added**：新增章節或規範項目
- **Changed**：修改既有規範的內容或細節
- **Deprecated**：即將移除但暫時保留的規範
- **Removed**：移除的章節或規範
- **Fixed**：修正錯字、邏輯錯誤、矛盾描述
- **Security**：安全相關規範的變更
